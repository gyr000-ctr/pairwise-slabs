# pairwise-slabs

## 题面（可直接粘贴）

给 2D 射线与轴对齐包围盒求交加 slab 实现，并满足几何退化与批量性能约束。约束：命中返回进入距离、未命中返回空；起点在盒内返回 0；与盒面相切（差 1e-12）必须判为命中；平行于某轴时不参与该轴区间；方向为零向量要报错；与暴力逐面求交在 1 万组随机输入上结果完全一致；批量 10 万条射线耗时不超过 1 秒且不分配逐条临时对象；同一 Ray 被多线程并发调用结果与串行一致；对 NaN 输入给可区分的错误。验收：python -m pytest tests -q -k hit。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

## 边界要求（评审侧隐藏用例判分，不在可见测试里）

- 边界上与盒面相切
- 极小/极大坐标
- 并发调用
- 时间上界
- 非有限输入

## 运行方式

```bash
python -m pytest tests -q
```
